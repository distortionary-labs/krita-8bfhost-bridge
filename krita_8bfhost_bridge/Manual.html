Photoshop Filters (8bf)

Runs Photoshop-compatible filter plug-ins (.8bf files) on paint layers through 8bf-host, a separate program you install yourself.

Getting started

  1. Download 8bf-host for your system from its releases page.
  2. Open Tools > Scripts > 8bf Filter Settings…. On the 8bf-host tab, set the location of the program (or leave it empty if it is on your PATH) and press Check Setup.
  3. Add the folders that contain your filters on the Folders tab. Subfolders are searched too. 8bf-host also searches the usual Adobe plug-in folders by itself.
  4. Select a paint layer, optionally make a selection, and choose a filter from Tools > Scripts > Photoshop Filters (8bf). The filter's window belongs to 8bf-host and may open behind Krita.
  5. The result is placed in a new layer above the active one. Change this on the 8bf-host tab; writing into the active layer cannot be undone with Ctrl+Z.

Supported layers

8-bit and 16-bit RGB and 8-bit grayscale paint layers. Filters that only support 8-bit images run on an 8-bit copy of 16-bit layers. Convert other layers first.

Linux

Windows filters run under Wine with the Windows build of 8bf-host. The 8bf-host documentation describes the setup; Check Setup shows whether it is complete.

Repeating a filter

Tools > Scripts > Repeat reruns the last filter with its last settings and without its dialog. You can assign it a shortcut under Settings > Configure Krita > Keyboard Shortcuts.
